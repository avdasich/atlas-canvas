# Статус технического задания

Проверено по `Atlas_Canvas_FULL_TZ.md`, версия исходников 0.3.0, 3 ноября 2026.
Это карта фактического состояния, а не объявление завершённой приёмки 1.0.

**Обозначения:** реализовано — код и доступный сценарий есть; частично — указан конкретный остаток; приёмка — требуется целевая машина или длительный пользовательский прогон. Автотесты не заменяют реальную проверку установщика и кодеков.

## Что реально проверено локально

- 40 frontend/domain-тестов и 13 Rust-тестов проходят; TypeScript/Vite и нативный macOS debug bundle собираются.
- Новая отдельная сборка восстановила полный `.atlas`: четыре объекта Японии, SVG→PNG, rich text, объединённая ячейка, шрифт/библиотеки и WAV. Воспроизведение WAV и отмена длинной URL-загрузки проверены в нативной среде.
- Экспорт/повторный импорт полного архива, контрольные суммы, пропуск/замена конфликтов, аварийная копия и rollback покрыты UI-прогоном/автотестами.
- После Cmd+Q копия тестовой SQLite проходит `integrity_check`; сцены 392 и 398 содержат соответственно 4 и 1000 объектов формата 4. Сохранён масштаб 100% большой сцены и preferences. После повторного запуска Япония открылась с прежним содержимым.
- Дублирование Cmd+D увеличивает число объектов, Cmd+Z возвращает его; Cmd+Enter завершает заметку, Shift+P/Esc переключают просмотр. В режиме просмотра ячейки доступны без редактора ввода.
- Большая сцена с 1000 фигурами импортирована и показана; Fit и 100% работают. Это проверка работоспособности, не измерение 60 fps.
- Нативный PDF прочитан Poppler: обычный холст — одна страница, тестовая высокая композиция — три страницы. Первая композиция также отрендерена и визуально проверена.
- Снимки работающего интерфейса включены в [руководство](USER_GUIDE.md).

## Что нужно до объявления 1.0

1. Завершить оставшиеся части P1: геометрические узоры, подготовку всех строк к английской локализации; отдельно определить необходимость безопасной очистки вложений.
2. Запустить подготовленный CI на macOS/Windows/Linux после push. В этой сессии удалённые Actions не запускались.
3. Проверить установщики, кодеки, системные диалоги, русские пути, HiDPI и клавиатуру на реальных Windows/Linux; автотест распознавания Ctrl не заменяет системную проверку.
4. Провести длительный прогон больших смешанных сцен, замер FPS/памяти, отказ доступа/переполнение диска и пользовательскую приёмку на настоящих заметках.
5. Проверить полноту лицензионных уведомлений после обновления зависимостей, настроить подписи пакетов для публичного выпуска.

Исходники 0.3.0 не отправлялись на GitHub из этой работы, тег и опубликованный релиз не создавались. Команды для владельца находятся в [RELEASE.md](RELEASE.md).
