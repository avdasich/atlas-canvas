# Keyboard shortcuts

Use **Cmd** on macOS and **Ctrl** on Windows/Linux. For example, Undo is Cmd+Z on Mac and Ctrl+Z on Windows/Linux.

## Essentials

| Action                                           | macOS                       | Windows and Linux           |
| ------------------------------------------------ | --------------------------- | --------------------------- |
| Add text                                         | T                           | T                           |
| Pan the canvas                                   | Space + drag / middle mouse | Space + drag / middle mouse |
| Fit everything                                   | F                           | F                           |
| Zoom to 100%                                     | 1                           | 1                           |
| Undo                                             | Cmd+Z                       | Ctrl+Z                      |
| Redo                                             | Cmd+Shift+Z / Cmd+Y         | Ctrl+Shift+Z / Ctrl+Y       |
| Copy / cut / paste between countries             | Cmd+C / Cmd+X / Cmd+V       | Ctrl+C / Ctrl+X / Ctrl+V    |
| Search notes, cells and expandable sections      | Cmd+F                       | Ctrl+F                      |
| Delete selection                                 | Delete / Backspace          | Delete / Backspace          |
| Finish text input                                | Cmd+Enter                   | Ctrl+Enter                  |
| Clear selection / cancel input / leave View mode | Esc                         | Esc                         |

## Mouse

- **Click** selects an object.
- **Shift+click** adds/removes an object or group from the selection.
- **Shift+drag on empty space** selects with a rectangle.
- **Wheel** zooms the canvas.
- **Drag empty space** pans.
- **Double-click a note** edits its text.
- **Right-click** opens the action menu.

Letter commands follow physical keys and also work with a Cyrillic keyboard layout. While typing in a note or cell, shortcuts affect text rather than canvas objects. Press Esc to leave View mode.

The same catalog appears in the app under **Properties → Keyboard shortcuts · all systems**.
