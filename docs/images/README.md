# Как добавить свои скриншоты

[Описание приложения](../../README.md) · [Руководство](../USER_GUIDE.md)

В документации уже стоят заглушки. Номера на них соответствуют списку ниже.
Их можно заменять постепенно — порядок и текст инструкции менять не нужно.

## Замена заглушки

1. Сделайте нужный снимок приложения. Лучше использовать демонстрационные записи без личных данных.
2. Сохраните PNG или JPG в эту папку с тем же именем, например **`05-text.png`**.
3. В Markdown-файле найдите имя заглушки и замените расширение **`.svg`** на **`.png`** или **`.jpg`**.

Например, в `docs/USER_GUIDE.md`:

```md
![Редактирование текста заметки](images/05-text.png)
```

Главная обложка в корневом `README.md` уже заменена реальным снимком `docs/screenshots/editor-snow.png`. Заглушку `01-overview.svg` можно использовать для будущей новой обложки, обновив ссылку в README.
Остальные снимки находятся в руководстве, а `02-installation` — в инструкции установки.
Старый SVG после замены ссылки можно убрать.

## Чтобы снимки были понятными

- Держите единый размер окна и тему интерфейса. У заглушек пропорции 16:9, но снимки могут иметь другой размер.
- Показывайте кнопку и результат действия в одном кадре, если они помещаются.
- Для общего вида заполните холст несколькими красивыми примерами; для отдельных инструментов уберите лишние панели.
- На снимке установки должен быть опубликованный выпуск с настоящим файлом установщика.
- Для переливания можно позже добавить GIF или видео; один кадр показывает только внешний вид фона.

После замены откройте предпросмотр README на GitHub или в редакторе и убедитесь, что картинки загрузились.
